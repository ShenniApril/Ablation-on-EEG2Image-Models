# Ablation-on-EEG2Image-Models
Our ablation framework to investigate EEG2Image Model's dependency on spectral, temporal and spatial neural features.

## Temporal Ablation
The `temporal` directory contains scripts, results, and assets for investigating the temporal dependency of the EEG2Image models. It includes:
- **`scripts/`**: Core execution scripts for temporal ablation (e.g., STFT, amplitude, generalization), statistical testing, and visualization.
- **`results/`**: Raw results generated from different phases of temporal ablation.
- **`assets/`**: Final visualizations, heatmaps, and summary charts (e.g., phase 2 heatmaps, generalization charts) related to temporal ablation experiments.
