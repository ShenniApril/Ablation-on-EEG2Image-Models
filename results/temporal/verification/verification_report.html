三、2 个 FAIL 的根因分析

❌ T6b — Phase3 函数存在 DC 均值偏移（脚本真实缺陷）

现象：ISTFT(仅保留 STFT bin0) 输出的均值 ≠ 原始段均值，偏差达 0.45（信号 RMS 量级约 0.5~1.0）

根因：
STFT 的 bin0 是 加窗后的局部 DC，受 Hann 窗形状影响：
Zxx[0, frame_k] ≈ Σ(signal[k·step : k·step+nperseg] × hann) / normalization
这与全局时域均值 signal.mean() 不等价。ISTFT 还原时，各帧叠加后的 DC 值会随窗位置漂移，最终导致均值偏移。

实验影响：Phase3 掩码会在目标时间窗引入约 0.45 μV 的均值阶跃。EEG encoder 中若含 BN/LN 层，该偏移可能被归一化吸收；但若无归一化，会产生模型输入分布的轻微偏移。

建议修复（一行）：
reconstructed += (original_mean - reconstructed.mean(axis=-1, keepdims=True))

⚠️ T7a — 验证脚本自身的参数不匹配（消融脚本无问题）

现象：在可视化 STFT 域内测量 box 内能量 ratio = 0.1194，略超阈值 0.10

根因：
• 掩码 STFT：nfft=64，频率分辨率 3.9 Hz
• 可视化 STFT：nfft=128，频率分辨率 1.95 Hz
两者频率 bin 不完全对齐，Hann 窗旁瓣将少量能量泄漏到可视化域的相邻 bin，导致约 11.9% 的"虚假残余"。

实际真相：T1a（掩码STFT参数下直接测量）已证明 gamma 能量被完全消除（ratio=0.0000）。T7a 的 FAIL 是验证脚本自己的问题，不是消融脚本的缺陷。

四、为什么这个验证策略是正确的

原则1：用"答案已知"的合成信号，而不是真实 EEG

真实 EEG 的频率成分未知、不稳定，无法精确计算"掩码后应该剩多少"。合成信号的每个频率成分的能量精确可控，可以计算出绝对正确的参考值，让任何偏差无处藏身。

原则2：验证"充分必要条件"，而非只验证"表面行为"

只验证表面行为（不够）验证充要条件（本方案做法）
输出信号看起来不一样 → 认为有效T1a：目标频段能量 ratio=0 → 充分证明确实被消除
没有报错 → 认为正确T1b：非目标频段 ratio=1.0000 → 排除误伤
—T2：窗外 RMSE=0 → 排除时间域污染
—T3：往返误差 1e-7 → 证明重建函数调用参数正确

这三个条件（能量消除 + 非目标保留 + 时间局部性）合在一起，构成了"STFT掩码正确工作"的充要条件。缺任何一个，消融实验结果都无法被解释为"某时频区域的贡献"。

原则3：隔离测试每条代码路径（边界条件覆盖）

T4 专门测试了短窗降级路径（T0时间窗13点 < STFT窗长32点）。若不测这个，可能在 T0 消融条件下悄悄跑了错误的代码路径而不自知。这类边界条件在实验脚本中极难通过人工代码审查发现。

原则4：时频图可视化提供直觉可信度验证

数值测试能发现"是否正确"，但时频图回答"为什么正确"——人眼可以直接看到能量在时频平面上被局部消除，框外完整保留，差异图精确局限在目标矩形内。这对实验可重现性和论文图表都有价值。
